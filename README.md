# Collaborative Editing
Collaborative-Editing in agent project

## 环境要求

本项目第一轮施工和本地开发需要：

- Node.js 20+
- pnpm
- Docker Desktop
- Docker Compose

验证命令：

```powershell
node -v
pnpm -v
docker version
docker compose version
```

当前已验证环境：

- Node.js: v24.9.0
- pnpm: 10.31.0
- Docker Desktop: 4.73.0
- Docker Engine: 29.4.3
- Docker Compose: v5.1.3

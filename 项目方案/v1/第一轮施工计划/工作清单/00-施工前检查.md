# 00-施工前检查

## 目标

确认本机环境、Git 状态和施工前提都准备好，避免后续初始化工程时被基础环境问题打断。

## 工作清单

- [ ✅️ ] 确认本机已安装 Node.js 20+
- [ ✅️ ] 确认本机已安装 `pnpm`
- [ ✅️ ] 确认本机可运行 Docker / Docker Compose
- [ ✅️ ] 确认当前分支正确
- [ ✅️ ] 确认工作区无未预期改动

## 验收标准

- `node -v` 可正常输出版本。
- `pnpm -v` 可正常输出版本。
- `docker version` 或 Docker Desktop 状态正常。
- `git status --short --branch` 显示在预期分支上。

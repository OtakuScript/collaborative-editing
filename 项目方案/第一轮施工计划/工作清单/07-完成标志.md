# 07-完成标志

## 目标

明确第一轮施工完成的判定标准，防止范围漂移。

## 工作清单

- [ ] 仓库具备可运行 monorepo 骨架
- [ ] 前端、API、协同服务都能独立启动
- [ ] PostgreSQL 能通过 Docker 启动
- [ ] Prisma schema 已建立
- [ ] 基础路由和健康检查可用
- [ ] 第一轮不包含的功能没有提前混入实现范围

## 第一轮不包含

- 真实注册登录逻辑。
- JWT 鉴权和前端登录态保持。
- 工作区 CRUD。
- 文档 CRUD。
- Tiptap 编辑器真实接入。
- Yjs 正文协同。
- Markdown 文件读写。
- 自动保存。
- 权限系统。
- E2E 测试。

## 验收标准

- 第一轮只交付可运行骨架。
- 后续功能已经留出结构位置，但没有提前进入实现。
- 可以基于该骨架继续拆第二轮施工计划。

# 02-前端 web-app

## 目标

搭建 `apps/web-app` 前端应用骨架，完成基础路由、Provider、布局和占位页面。

## 工作清单

- [ ] 创建 `apps/web-app`
- [ ] 初始化 Vite React TypeScript 项目
- [ ] 安装 React Router
- [ ] 安装 TanStack Query
- [ ] 安装 Zustand
- [ ] 安装 Ant Design
- [ ] 配置应用入口
- [ ] 配置全局 Provider
- [ ] 配置基础 Layout
- [ ] 创建 `/login` 页面
- [ ] 创建 `/register` 页面
- [ ] 创建 `/workspaces` 页面
- [ ] 创建 `/workspaces/:workspaceId/documents` 页面
- [ ] 创建 `/documents/:documentId` 页面
- [ ] 登录页显示邮箱、密码、登录按钮
- [ ] 注册页显示邮箱、昵称、密码、注册按钮
- [ ] 工作区页显示占位列表
- [ ] 文档列表页显示占位列表和新建按钮
- [ ] 文档编辑页显示工具栏、编辑区、连接状态占位
- [ ] 确认五个路由都能访问

## 验收标准

- `web-app` 可以本地启动。
- 浏览器可以访问 `http://localhost:5173`。
- 五个基础路由都能正常渲染占位页面。
- 前端暂不接真实登录、文档和协同业务。

# 06-验收

## 目标

验证第一轮工程骨架可安装、可构建、可启动、可访问。

## 工作清单

- [ ] 执行 `pnpm install`
- [ ] 执行 `pnpm typecheck`
- [ ] 执行 `pnpm build`
- [ ] 执行 `docker compose up postgres`
- [ ] 启动 `api-service`
- [ ] 请求 `GET /health`
- [ ] 启动 `web-app`
- [ ] 打开 `http://localhost:5173`
- [ ] 验证五个前端路由
- [ ] 启动 `collab-service`
- [ ] 验证 `1234` 端口监听
- [ ] 用 WebSocket 客户端连接协同服务
- [ ] 确认服务端打印连接日志

## 验收标准

- 依赖安装成功。
- 类型检查通过。
- 构建通过。
- PostgreSQL 可启动。
- API 健康检查正常。
- 前端页面可访问。
- 协同服务可接受 WebSocket 连接。
